# Insurance Purchase Prediction Web Application

## Project Overview

This project is an end-to-end Machine Learning web application that predicts an individual's **Insurance Premium Category (High, Medium, or Low)** based on personal, health, lifestyle, and socioeconomic factors.

The application uses a **Logistic Regression** model trained on engineered features and is deployed using **FastAPI** for the backend and **HTML, CSS, and JavaScript** for the frontend.

---

## Features

- Predicts insurance premium category:
  - High
  - Medium
  - Low
- Input validation using Pydantic
- Automatic feature engineering
- FastAPI REST API backend
- Interactive HTML/CSS frontend
- JavaScript integration with backend API
- Logistic Regression model saved as `model.pkl`

## Feature Engineering

### 1. BMI (Body Mass Index)

BMI is calculated using:

```python
BMI = Weight / Height²
```

This helps estimate health risk based on height and weight.

---

### 2. Age Group

Users are categorized into age groups:

```text
Age < 25           → Young
25 ≤ Age < 45      → Adult
45 ≤ Age < 60      → Middle Aged
Age ≥ 60           → Senior
```

---

### 3. Lifestyle Risk

Lifestyle risk is determined using smoking status and BMI:

```text
Smoker + BMI > 30      → High Risk
Smoker OR BMI > 27     → Medium Risk
Otherwise              → Low Risk
```

---

### 4. City Tier

Cities are classified into:

```text
Tier 1
Tier 2
Tier 3
```

based on urban classification and cost of living.

---

## Machine Learning Pipeline

### Preprocessing

#### Categorical Features

- age_group
- lifestyle_risk
- occupation
- city_tier

Processed using:

```python
OneHotEncoder()
```

#### Numerical Features

- bmi
- income_lpa

Used directly in the model.

---

### Model

```python
LogisticRegression(max_iter=1000)
```

The model is trained using Scikit-Learn Pipeline and saved as:

```text
model.pkl
```

## API Endpoint

**POST**
